# ✋ AR Hand Tracker 2.0 & Multiplayer Duels | Uniwersalna wersja (iPad, Android, Huawei, PC)

Aplikacja Augmented Reality (AR) do śledzenia 56+ biometrycznych punktów dłoni, rozpoznawania gestów i pojedynków multiplayer w czasie rzeczywistym.

---

## 📱 Obsługiwane urządzenia:
- **Apple iPad / iPhone** (Safari & Chrome na iPadOS/iOS – obsługa `webkit-playsinline`, WebKit Audio)
- **Huawei MatePad / HarmonyOS** (Huawei Browser, Petal)
- **Samsung Galaxy Tab / Android** (Google Chrome, Samsung Internet)
- **Komputery PC / Mac / Laptopy** (Chrome, Edge, Firefox, Brave)

---

## 🌟 Nowe ulepszenia i uniwersalny start:
1. **Uniwersalne uruchamianie kamery**:
   - Bezpośredni przycisk **"URUCHOM KAMERĘ"** z natywnym wyzwalaczem dotykowym.
   - **Alternatywny start**: Jeśli klikniesz dowolną mini-grę (np. 🍉 *Fruit Slicer*) lub przycisk kamery `🔄`, kamera uruchomi się automatycznie!
2. **Pełne wsparcie dla iPadów (iPadOS)**:
   - Dodano atrybuty wideo `webkit-playsinline`, które są wymagane przez system Apple do odtwarzania kamery wewnątrz strony.
   - Zabezpieczono aktywację dźwięku Web Audio API pod restrykcyjne wymogi Safari.
3. **56+ Biometrycznych Punktów Dłoni (Przycisk `🔬`)**:
   - Dokładna siatka dłoni, węzły stawów i cybernetyczny wireframe.
4. **Pojedynki Multiplayer przez kod pokoju (Przycisk `⚔️`)**:
   - Możliwość rywalizacji z kimś z innego Wi-Fi lub na danych komórkowych!
5. **Gra "Złap Gwiazdy" (✊)**:
   - Złapanie gwiazdki następuje po zaciśnięciu dłoni w pięść.
